# Ресторан басқару жүйесі

Толық функционалды ресторан басқару жүйесі Visual Studio Code үшін.

## Техникалық талаптар

✅ Барлық беттер толық жұмыс істейді
✅ Барлық кнопкалар функционалды
✅ Барлық модульдер бір-бірімен интеграцияланған
✅ Міндетті авторизация
✅ Рөлдік қолжетімділік

## Функционал

### 1. Авторизация
- Логин/Пароль
- Рөл таңдау (Админ/Менеджер/Аспаз/Официант/Кассир)
- Автоматты рөл бойынша қолжетімділік

### 2. Мәзір басқару
- Тағам қосу/өзгерту/жою
- Баға енгізу
- Сурет жүктеу
- Санаттар: бірінші тағам, екінші тағам, салат, десерт, сусындар
- Статус: бар/жоқ

### 3. Тапсырыс жүйесі
- Үстел таңдау
- Тағамдарды себетке қосу
- Тапсырыс беру
- Статус: қабылданды → дайындалуда → дайын → жеткізілді
- Тапсырысты түзету/болдырмау
- Чек шығару

### 4. Үстел брондау
- Бос үстелдерді карта түрінде көрсету
- Сағат бойынша брондау
- Клиент ақпараттары
- Бронды өзгерту/жою

### 5. Клиенттер базасы
- Клиент туралы ақпарат
- Жиі келетін клиенттер тізімі
- Бонус жүйесі
- Жеңілдіктер

### 6. Төлем және есеп-қисап
- Қолма-қол төлем
- Картамен төлем
- QR төлем
- Чек генерациялау
- Күндік, апталық, айлық табыс есептері

### 7. Қызметкерлер басқару
- Қызметкер аккаунттары
- Логин/Пароль
- Рөлдер: Админ, Менеджер, Аспаз, Официант, Кассир
- Рөлдер бойынша қолжетімділікті шектеу

### 8. Асхана панелі
- Аспазға арналған тапсырыстар тізімі
- Қай тағам дайын
- Уақытты есептеу
- Статус көрсету (қызыл/сары/жасыл)

### 9. Қойма жүйесі
- Ингредиенттер тізімі
- Қалған өнім мөлшерін бақылау
- Автоматты «аз қалды» ескерту
- Қоймаға жеткізу қабылдау

### 10. Админ панель
- Барлық модульдерді толық басқару
- Статистика, диаграммалар
- Резервтік көшіру
- Деректерді экспорттау
- Кіру журналы

### 11. Қауіпсіздік
- Парольдер шифрлануы
- SQL Injection-нан қорғау
- Рөлдік қолжетімділік
- Кіру журналын жүргізу

## Бастау

1. Барлық файлдарды бір папкаға салыңыз
2. `index.html` файлын браузерде ашыңыз
3. Авторизациядан өтіңіз

## Тесттік аккаунттар

- **Админ**: логин: `admin`, пароль: `admin123`
- **Менеджер**: логин: `manager`, пароль: `manager123`
- **Аспаз**: логин: `chef`, пароль: `chef123`
- **Официант**: логин: `waiter`, пароль: `waiter123`
- **Кассир**: логин: `cashier`, пароль: `cashier123`

## Ескерту

Деректер localStorage-да сақталады. Браузер деректерін тазаласаңыз, барлық ақпарат жоғалады.

## Технологиялар

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage (деректер сақтау үшін)
