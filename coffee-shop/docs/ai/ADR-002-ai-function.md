# ADR-002. Пікір талдауына жергілікті Qwen

- **Status:** accepted
- **Date:** 2026-11-25

## Контекст

Ресторан қосымшасында пікір модулі бар. Менеджерге пікірдің эмоциясы, санаты, маңыздылығы және жауап ұсынысы керек. Клиентке хат өзі кетпеуі керек. Ақылы API кілті жоқ. Ollama осы машинада орнатылмаған.

## Қарастырылған нұсқалар

1. Ollama + Qwen, `http://127.0.0.1:11434`.
2. Жергілікті GGUF, Qwen2.5-1.5B-Instruct, `node-llama-cpp`, сол JSON келісімі.
3. Коммерциялық API, gpt-5-mini немесе gpt-4o-mini.
4. Кілтсөзді AI нәтижесі деп көрсету.

## Таңдалған шешім

Жұмыс істейтін қозғалтқыш: **2-нұсқа**. Конфигурация `provider` өрісімен Ollama-ға ауысады. Ollama қосылмаса және `provider` сол болса, экран қате көрсетеді, ойдан нәтиже жоқ.

## Неге

Ollama жоқ. Жергілікті файл сол Qwen отбасы және тегін. Коммерциялық API осы көлемде арзан, бірақ кілт жоқ және пікір сыртқа шығады. Кілтсөзді AI деп атау тапсырмаға қайшы.

## Артықшылығы

Дерек компьютерден шықпайды. Модельді `ai-config.json` арқылы ауыстыруға болады. Жауап жіберілмейді.

## Кемшілігі

1.5B қазақшада жиі қателеседі. CPU-да бір пікір секундтар алады. Сапаны алдын ала уәде етуге болмайды.

## Қаупі

Жалған сенім: менеджер ұсынысты тексермей көшіріп жіберуі. Бұған жіберу батырмасының жоқтығы қарсы тұрады.

## Болашақ

Ollama орнаса, `provider` мәні `ollama`, модель `qwen2.5:1.5b`. Эталон 32 жолды қайта өлшемей модельді ауыстырмаймыз. RAG пен агент пікір сыныбына керек емес.
