# AI функциясының карточкасы

**Функция:** AI Restaurant Assistant, пікірді талдау  
**Күні:** 2026-11-25  
**Қосымша:** Ресторан басқару жүйесі, `localStorage`, HTML/CSS/JS

| Өріс | Мәні |
| --- | --- |
| Кіріс | Пікір мәтіні. Аты мен телефон модельге жіберілмейді |
| Шығыс | sentiment, category, priority, summary, suggested_reply, confidence |
| Қозғалтқыш | Конфигурация: `ollama` немесе `local`. Қазіргі жергілікті файл: Qwen2.5-1.5B-Instruct Q4 |
| Ауыстыру | `ai-config.json`. Жеке жол `ai-config.local.json` ішінде, ол Git-ке кірмейді |
| Адам | Менеджер немесе админ. Ұсынылған жауап клиентке өзі жіберілмейді |
| Қате | Модель жоқ болса экранда қате. Кілтсөз нәтижесі AI деп көрсетілмейді |

Бизнес өлшемі: жоғары маңызды негативті пікірді менеджер сол ауысымда көреді. Модель өлшемі: sentiment, category және priority дәлдігі, sentiment бойынша macro-F1. Қабылдау шегі бұл аптада бекітілмеген уәде емес: өлшем нәтижесі `eval-results.md` ішінде, ол нақты жүгірту.

AI-сыз бағдар: `ai/baseline.js` кілтсөз ережесі. Ол тек салыстыру үшін, экранда AI нәтижесінің орнына тұрмайды.

Промпт жеткілікті: бір қысқа пікір, жабық сыныптар. RAG керек емес, өйткені мәзір парағын іздемейміз. Қосымша оқыту мен агент бұл нұсқада жоқ.
